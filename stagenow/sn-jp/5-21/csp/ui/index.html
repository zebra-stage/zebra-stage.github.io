SmartDocs について


[SmartDocs] バーでは、特定の Zebra デバイスに存在する機能のみを表示するように、このページをカスタマイズできます。

  1. ドロップダウンを使用してデバイスの OSX、MX、Android のバージョンを選択するか、デバイスのモデルを選択すると、デバイスでサポートされている機能が強調表示されます。サポートされていない機能は、選択内容に基づいてグレー表示になります。
  2. SmartDocs Nav は、個々の CSP の機能を表示するときに機能します。使用するには、CSP (つまり「App Manager」) をクリックし、SmartDocs バーで少なくとも 1 つを選択します。サポートされていない機能はグレー表示になります。その CSP でサポートされている機能の間を前後にスクロールさせるには、SmartNav の [進む] ボタンと [前へ] ボタンをクリックします (機能マトリックスでは SmartNav はサポートされていません)。
  3. すべての選択をクリアするには、[SmartDocs] ボタンを押します。

デバイスの OSX、MX および Android のバージョン情報は、Android の設定パネルに表示されるか、ADB、EMDK、または MX CSP を使用してデバイスを照会することで確認できます。詳細情報。

  • OSX レイヤーは、Android で提供されていない機能を実装するために、基本オペレーティング システムの拡張機能を提供します。ルート OSX のバージョン番号は、拡張対象とする Android バージョンのルート番号と常に一致します。詳細情報。
  • MX 管理システムは、デバイス上の特権および非特権 Android API に対して、統一されたインタフェースを提供します。一部の機能では、MX バージョンと OSX バージョンの特定のペアリングが必要です。詳細情報。
  • 機能セットを決定するには、Android バージョンで十分な場合があります。また、特定の MX バージョンと Android の最小バージョンが必要になる場合もあります。
  • デバイス モデルは、MX 機能のどのサブセットがデバイスに存在するかを示します。

概要

UI Manager (UiMgr) では、言語とロケール、デバイス通知のプルダウン、クイック設定のコントロール、デフォルトの入力デバイス、クリップボードの動作など、さまざまな UI 設定を制御できます。

Android デバイスには、OS 全体に存在する UI 要素にアクセスするさまざまなシステム アプリケーションが入っています。これまでに企業に導入されたデバイスについて、これら "標準" の UI 要素のうちの 1 つまたは複数が、Zebra の顧客またはパートナーから望ましくないと見なされたケースがあります。UiMgr では、これらの UI 要素を制御することができます。また、特定の業務に従事するデバイス ユーザーの生産性を妨げる可能性がある Android の動作や機能を無効化するオプションもあります。

セキュリティの警告: UiMgr を使用して、「ネットワークが監視されている可能性があります」というメッセージを抑制できます。この重要な保護機能は、セキュリティ リスクの可能性をデバイス ユーザーに警告することを目的としています。管理者は、CA 証明書が適切に検証された上でデバイスにインストールされていない限り、このメッセージを抑制してはなりません。また、メッセージが抑制されている間は、信頼できない証明書を後からインストールできないようにする必要があります。

外部 KB レイアウト

設定中のキーボード レイアウトの名前を入力するために使用します。これは必須フィールドとなり、デバイスの [キーボード レイアウト] パネルにあるレイアウト名を必ず含めなければなりません (大文字と小文字を区別)。MX 13.2 以降を搭載したデバイスにおいては、キーボード レイアウト マッピング追加時の指定言語が [自動] の場合、キーボードが接続されるたびにデバイス ロケールが自動的に設定されます。

キーボード レイアウトを表示するには:

  1. [Android 設定] パネルに移動します。
  2. [システム] > [言語と入力] > [物理キーボード] を選択します。†
  3. 接続されている外部キーボードの名前をタップします。現在選択されているレイアウトの名前が表示されます。
  4. [キーボード レイアウトの設定] をタップして、代替レイアウト (言語) のリストを表示します。
    † オプション ラベルは Android のバージョンによって異なります。

パラメータ値入力ルール:

  • 1 文字以上の英数字の文字列

ワークフロー アクション

ワークフローを管理するためのアクションを制御するために使用され、作業アクティビティ用に指定されたアプリが自動的に起動されます。ワークフローに対して複数のアプリが選択されている場合、アプリは分割画面モードで同時に表示され、以下で説明する動作の対象になります。

この機能は、Android 13 以降を実行しているデバイスではサポートされません。

分割画面の動作:

  • 一度設定されると、ワークフローはデバイスの再起動のたびに実行されます。分割画面モードが無効化されても、ワークフローが削除されない限り、動作は変わりません。
  • 分割画面モードを実行および維持するように設定されたデバイスでエンタープライズ リセットを実行しても、再起動時にアプリが自動的に起動し、分割画面モードではなく、単独で実行されます。
  • 単一アプリのワークフローでは、指定されたアプリを全画面モードで起動します。 分割画面モードを有効にする必要はありません。
  • デバイス ユーザーが手動で作成した分割画面シナリオは、デフォルトでは 50:50 の画面比率で実行されます。
  • どのような分割画面シナリオでも、分割線をドラッグすることで画面比率を手動で変更できます。
  • 次の場合、デバイスの分割画面モードは終了します。。
    • ワークフロー アプリがクラッシュした場合。
    • ワークフロー アプリが adb 経由でアップグレードされる。
  • 次の場合、ワークフローが起動しないか、正常に起動しないか、ステージング エラーが発生する可能性があります。:
    • デバイスで分割画面機能が無効になっている。
    • ターゲット デバイスに 1 つ以上の指定されたアプリが存在しない。
    • 1 つ以上の指定されたアプリが分割画面モードをサポートしていない。
    • 最初にインストールされたときに、1 つ以上の指定されたアプリでポップアップ メッセージが表示された。
    • ターゲット デバイスで分割画面が無効になった後に、ワークフローが構成および展開される。
  • StageNow クライアント アプリケーションは、分割画面モードをサポートしていません。

分割画面を終了する方法:

  • 分割線を画面の左上または右下にドラッグする
  • HOME ボタンを押し、分割線を任意の方向にドラッグする
  • 最初のアプリにフォーカスがあるときに BACK ボタンを押す
  • 2 番目のアプリにフォーカスがあるときに BACK ボタンを押し、分割線を引く

注: Android 11 を実行しているデバイスでのみサポートされます。
