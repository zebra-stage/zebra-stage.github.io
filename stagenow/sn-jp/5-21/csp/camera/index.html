SmartDocs について


[SmartDocs] バーでは、特定の Zebra デバイスに存在する機能のみを表示するように、このページをカスタマイズできます。

  1. ドロップダウンを使用してデバイスの OSX、MX、Android のバージョンを選択するか、デバイスのモデルを選択すると、デバイスでサポートされている機能が強調表示されます。サポートされていない機能は、選択内容に基づいてグレー表示になります。
  2. SmartDocs Nav は、個々の CSP の機能を表示するときに機能します。使用するには、CSP (つまり「App Manager」) をクリックし、SmartDocs バーで少なくとも 1 つを選択します。サポートされていない機能はグレー表示になります。その CSP でサポートされている機能の間を前後にスクロールさせるには、SmartNav の [進む] ボタンと [前へ] ボタンをクリックします (機能マトリックスでは SmartNav はサポートされていません)。
  3. すべての選択をクリアするには、[SmartDocs] ボタンを押します。

デバイスの OSX、MX および Android のバージョン情報は、Android の設定パネルに表示されるか、ADB、EMDK、または MX CSP を使用してデバイスを照会することで確認できます。詳細情報。

  • OSX レイヤーは、Android で提供されていない機能を実装するために、基本オペレーティング システムの拡張機能を提供します。ルート OSX のバージョン番号は、拡張対象とする Android バージョンのルート番号と常に一致します。詳細情報。
  • MX 管理システムは、デバイス上の特権および非特権 Android API に対して、統一されたインタフェースを提供します。一部の機能では、MX バージョンと OSX バージョンの特定のペアリングが必要です。詳細情報。
  • 機能セットを決定するには、Android バージョンで十分な場合があります。また、特定の MX バージョンと Android の最小バージョンが必要になる場合もあります。
  • デバイス モデルは、MX 機能のどのサブセットがデバイスに存在するかを示します。

概要

CameraMgr は、画像をキャプチャできるデバイス上のカメラおよびその他のメカニズムへのアクセスを制御します。Zebra Android 製品の多くには、写真の撮影、バーコードのスキャン、またはデータ/ドキュメント/画像の取得に使用できるデバイスが搭載されています。環境を安全に保つために、CameraMgr を使用して写真撮影とドキュメントのキャプチャを制限し、カメラやカメラ以外のデバイスによる潜在的なセキュリティ リスクを排除することができます。

重要: デバイス上で写真撮影または画像のキャプチャに使用できるメカニズムはいずれも、CameraMgr によってカメラとして扱われます。たとえば、デバイスに CCD ベースのイメージャが搭載されており、主にバーコードのスキャンが目的であるが、写真を撮影する手段もサポートされているという場合は、UseAllCameras (有効/無効) パラメータを使用して、そのイメージャの写真撮影機能を無効にすることができます。これにより写真を撮影できない場合も、バーコード スキャン機能は動作し続けます。このようなデバイスがバーコードのスキャンしかできない場合は、画像のセキュリティにほとんどリスクがないため、カメラとしては扱われません。

主な機能

  • すべてのカメラおよび画像キャプチャ デバイスの使用を有効化/無効化
  • 前面カメラの有効化/無効化
  • 背面カメラの有効化/無効化
  • イメージャ カメラの有効化/無効化
  • カメラと画像キャプチャ デバイスのどれが有効/無効になっているかを報告

注意事項

  • カメラ API を使用したイメージャからの画像キャプチャは、Android 8.x (Oreo) 以降を実行しているデバイスではサポートされていません。
  • カメラ以外のデバイスを使用した写真撮影の限定的なサポートは、Android 5.x 以降を実行しているデバイスで利用できる場合があります。
  • バーコード スキャンによって直接的または間接的に写真を撮影できる場合、一部またはすべてのカメラをブロックすることで、それらのカメラを使用したバーコード スキャンができなくなるという可能性もあります。
  • 一部またはすべてのカメラをブロックすると、それらのカメラを使用した SimulScan の使用も禁止されることがあります。これは、SimulScan の機能の一部または全体が写真撮影の機能に依存していることがあるためです。
  • Android 5.x を実行しているデバイスでイメージャをブロックすると、SimulScan が無効になります。

Zebra Camera アプリ

Zebra Camera アプリ (ZCA) は、ほとんどの Zebra デバイスにプリインストールされている画像キャプチャ アプリです (下記を参照)。ZCA 設定は、ローカルでデバイス ユーザーが構成することも、リモートで JSON ファイルをデバイスにプッシュして構成 (ユーザー構成の設定を上書き)することも可能です。一部のパラメータでは、ユーザーが変更できないように設定することもできます。手順と設定可能なパラメータを以下に示します。

プライバシー ブラー

Zebra Camera アプリ 2.6 はプライバシー ブラーを実装しています。これは、保存時にキャプチャ画像で検出された人の顔を自動的にぼかす機能となります。画像のプレビューや動画のキャプチャでは、ブラーは表示されません。

ぼかしは上の画像のように表示されます。

注意事項

  • 現在は、1.0 倍のズームのみサポートしています。
  • 顔検出を有効にする必要があります (デフォルトはオン)。
  • キャプチャ時にカメラが過度に動くと、顔のぼかしが不正確になる可能性があります。
  • ブラーを有効にすると、画像の保存に時間がかかります。待ち時間は利用可能な計算能力によって異なります。

Image Quality Screener

Zebra Camera アプリ 2.5.13 (以降) は、Zebra Image Quality Screener (IQS) を実装しています。IQS は、デバイス ユーザーがキャプチャした画像の品質を向上させることができる機能です。IQS では AI を使用して、動きや不適切なフォーカスなどによる画像のぼやけを分析し、ユーザーや管理者が組織の要件に基づいて設定した事前定義のしきい値を超える画像に対しては、ユーザーに再撮影を促します。


パフォーマンス

  • IQS によるぼやけの評価は、Zebra テスターが同じ画像を判定した結果と 0.6 ポイント* 以内の差でした。
  • 16MP 画像 (Zebra のデフォルト) の場合、ぼやけを IQS で評価するのに 300 ～ 400 ミリ秒かかります。†

イメージ/キャプチャ サポート

  • JPEG (.jpg) ファイル形式で保存された静止画像
  • 単一イメージ キャプチャのみ

使用上の注意

  • OCR またはバーコードのデコード用の画像の場合、通常、成功するにはシャープネスの低いしきい値が必要です。
  • 製品認識用の画像の場合、通常、成功するにはシャープネスの高いしきい値が必要です。
  • ぼやけのスコアが不良または不正確な場合、次の原因が考えられます。
    • テクスチャのない (ほぼない) 領域を含む画像 (何もない白い壁、広々とした空など)
    • 被写体の外側にぼやけた領域を広く含んだクローズアップ ショット
    • ハイ ダイナミック レンジ (HDR) や マルチフレーム ノイズ リダクション (MFNR) などの機能の使用
    • バースト キャプチャおよび連続ショット モードが非サポート

* ぼやけは、1 ～ 5 段階で評価されます (1 = 不鮮明、5 = 鮮明)。
† 結果はデバイスのプロセッサや画像サイズによって異なります。IQS 評価はすべてデバイス上で実行されます。

導入

  1. 目的の ZCA 設定の値を有する config.json ファイル を作成 (または上記のサンプルを編集) します。
  2. Zebra Secure Storage Manager (SSM) を使用して、ファイルをデバイスにプッシュします。
  3. 選択したステージング ツール* で、ファイル マネージャ (または EMM 相当) を使用して導入プロファイルを作成し、バーコードまたは XML/eXML を生成します。
  4. デバイスでバーコードをスキャンするか、XML/eXML をリモートで実行するようにプッシュして、デバイスにプロファイルを適用します。
    * Zebra DNA クラウド、OEMConfig、StageNow、または企業独自の EMM システムをサポートします。

設定は、次回 Zebra Camera アプリを起動したときに有効になります。

導入の詳細については「Zebra アプリでの SSM の使用」を参照してください。

注意と動作

  • デバイス ユーザーによる Zebra Camera アプリ設定の変更は一時的なものです。オンデバイス設定ファイルの設定は、アプリを起動するたびに適用されます。
  • 対応する機能 (GoogleLens など) がデバイスに存在しない場合、設定ファイルに含まれる設定は無視されます。
  • Zebra Camera アプリをデフォルト設定に戻すには、デバイスから config.json ファイルを削除して再起動します。
  • Camera Manager MX コンポーネントは、Zebra Camera アプリやデバイス ユーザーによる当該機能へのアクセスに影響を与えません。

    • [オン] にすると、機能がアクティブになります。

すべてのカメラを有効化/無効化

デバイス上にあるカメラとカメラに分類されるその他のメカニズムすべてに関して、使用を有効化/無効化するために使用します。このパラメータを [すべてのカメラを無効化] にして使用すると、デバイス上に写真撮影用のアプリケーションが存在している場合でも、写真の撮影ができなくなります。注: デバイスによっては、すべてのカメラを無効にすると SimulScan アプリやスキャナ、また明示的にカメラとして記載されていないデバイス、写真撮影を目的としていないデバイスなどが無効にされる場合があります。

Android L 以降を実行しているデバイスでは、カメラ以外のデバイスを使用した撮影のサポートが制限されている場合があります。

重要: このパラメータは、デバイス上で CameraMgr がカメラとして分類するすべてのメカニズムを制御します。CameraMgr パラメータを個別に使用して制御できる数よりも多くのカメラがデバイスに搭載されている場合でも同様です。たとえば、デバイスに前面カメラと背面カメラが装備されており、ドキュメントをキャプチャできるイメージャが側面に装備されている場合、この 3 つのデバイスはすべてカメラとして分類されるため、このパラメータを使用してまとめて有効/無効にすることができます。この場合、側面のイメージャを個別に制御するには、まず最初に 3 つの「カメラ」をすべて有効にして、次に前面と背面のカメラをそれぞれ対応するパラメータを使用して無効にしなければなりません。

また重要な注意点として、すべてのカメラを有効または無効にすると、個々のカメラ アプリによる以前の類似コマンドがオーバーライドされる場合があります。さらに、その後に他のアプリが CameraMgr を使用してコマンドを発行すると、それにより個々のカメラの設定がオーバーライドされることもあります。

以前に CameraMgr によって有効/無効にされたカメラおよびその他のイメージング デバイスは、他の方法で明示的に指定されるまで、その状態を保ちます。
