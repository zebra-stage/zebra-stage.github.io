SmartDocs について


[SmartDocs] バーでは、特定の Zebra デバイスに存在する機能のみを表示するように、このページをカスタマイズできます。

  1. ドロップダウンを使用してデバイスの OSX、MX、Android のバージョンを選択するか、デバイスのモデルを選択すると、デバイスでサポートされている機能が強調表示されます。サポートされていない機能は、選択内容に基づいてグレー表示になります。
  2. SmartDocs Nav は、個々の CSP の機能を表示するときに機能します。使用するには、CSP (つまり「App Manager」) をクリックし、SmartDocs バーで少なくとも 1 つを選択します。サポートされていない機能はグレー表示になります。その CSP でサポートされている機能の間を前後にスクロールさせるには、SmartNav の [進む] ボタンと [前へ] ボタンをクリックします (機能マトリックスでは SmartNav はサポートされていません)。
  3. すべての選択をクリアするには、[SmartDocs] ボタンを押します。

デバイスの OSX、MX および Android のバージョン情報は、Android の設定パネルに表示されるか、ADB、EMDK、または MX CSP を使用してデバイスを照会することで確認できます。詳細情報。

  • OSX レイヤーは、Android で提供されていない機能を実装するために、基本オペレーティング システムの拡張機能を提供します。ルート OSX のバージョン番号は、拡張対象とする Android バージョンのルート番号と常に一致します。詳細情報。
  • MX 管理システムは、デバイス上の特権および非特権 Android API に対して、統一されたインタフェースを提供します。一部の機能では、MX バージョンと OSX バージョンの特定のペアリングが必要です。詳細情報。
  • 機能セットを決定するには、Android バージョンで十分な場合があります。また、特定の MX バージョンと Android の最小バージョンが必要になる場合もあります。
  • デバイス モデルは、MX 機能のどのサブセットがデバイスに存在するかを示します。

概要

Green Mode Manager (GreenModeMgr) を使用すると、消費電力を最小限に抑えられるようにデバイスを設定することができます。具体的には、最もエネルギーを消費するデバイス コンポーネントへの電力供給のスケジュールを設定します。これは、コンポーネントがアクティブなると予想されるタイミングに合わせて電力供給を実行するものとなります。また、デバイス センサーが特定の状態を示したときにコンポーネントを停止させることもできます。

主な機能

  • 以下に対して電源供給のスケジュールを設定する。
    • Bluetooth 無線
    • モバイル データ通信 (WWAN) 無線機能
    • NFC 無線機能
    • デバイスに接続されている周辺機器
    • Wi-Fi (WLAN) 無線機能
  • 次の場合にディスプレイがオフになるようデバイスを設定する。
    • 充電中
    • 指定した時間
    • アイドル状態が一定時間続いたとき
    • 下向きの状態が一定時間続いたとき
    • 一定時間にわたり、低光量状態が検出されたとき
  • デバイスが Wi-Fi ネットワークに接続すると、WWAN 無線が自動的にオフになる
  • 低光量状態が一定時間続いたとき、ディスプレイ バックライトが自動的に暗くなる。
  • [Android 設定] パネルで [明るさの自動調整] が無効になると、ディスプレイ バックライトが自動的に暗くなる。

Green Mode Manager は、SDM660 プラットフォーム デバイスではサポートされていません。プラットフォーム別の Zebra デバイスのリストを参照してください。

下に向けたときに画面をオフ

一定時間 ([下向き時の消灯遅延時間] パラメータ (下記) で指定された時間) にわたり、画面を下向きにしてユニットが置かれている状態が続いたときに、デバイス画面をオフにするかどうかを制御します。

注: SDM660 プラットフォーム デバイスではサポートされていません。

パラメータ名: ScreenProximityState

オプション 名前 説明注記 ステータス 要件
0 変更しない この値が選択されている (または XML からこのパラメータが提示されない) 場合、設定は変更されず、以前に選択した設定が保持されます。

MX: 15.0+
1 オンにする 画面を下に向けた状態でデバイスが置かれると、画面がオフになります。

MX: 15.0+
2 オフにする デバイスが下向きの状態で置かれても、画面をオンのままにします。

MX: 15.0+

画面自動減光

デバイスの周囲光センサーが、[自動減光パーセンテージ] パラメータで指定されたレベルの低光量状態を検出したときに、画面の輝度を自動的に減光するかどうかを制御します (下記)。

動作に関するメモ

Android システムの場合、このパラメータの動作は、[明るさの自動調整] 設定により異なります。

  • [明るさの自動調整] が有効の場合、パラメータが適用されると以下のようになります:
    • 輝度が、指定の割合 (または 30% のいずれか大きい方) までただちに減少。
    • 画面の輝度が、周囲の明るさの状態に応じて調整される
  • [明るさの自動調整] が無効の場合、パラメータが適用されると以下のようになります:
    • 輝度が、指定の割合 (または 30% のいずれか大きい方) までただちに減少。
    • デバイス ユーザーによる変更や新しい設定の適用がない限り、輝度は同じレベルを維持

注: SDM660 プラットフォーム デバイスではサポートされていません。

パラメータ名: ScreenBrightnessState

オプション 名前 説明注記 ステータス 要件
0 変更しない この値が選択されている (または XML からこのパラメータが提示されない) 場合、設定は変更されず、以前に選択した設定が保持されます。

MX: 15.0+
1 オンにする 低光量状態が検出されると、画面が自動的に暗くなります。前述の「動作に関するメモ」を参照してください。

MX: 15.0+
2 オフにする 低光量状態が検出されても、画面は自動的に減光されません。

MX: 15.0+

自動減光パーセンテージ

画面の輝度を現行レベルから落とすパーセンテージ ポイント (10 ～ 30) を入力する際に使用します。たとえば、80% に設定されているデバイスで「30」と入力すると、輝度が 50% になります。このパラメータを適用した場合、パラメータの入力値やデバイスの現在の輝度レベルに関係なく、画面の輝度が 30% 未満になることはありません。

パラメータ値入力ルール:

  • 10 ～ 30 の整数

注: SDM660 プラットフォーム デバイスではサポートされていません。

次の場合に表示: 画面の輝度状態 (自動減光) が [オン]

パラメータ名: ScreenBrightnessLevel

要件:

  • MX: 15.0+

Wi-Fi 通話が利用できない場合やデバイスで有効になっていない場合、この機能を呼び出すと、すべての電話使用が一切できなくなる可能性があります。

オプション 名前 説明注記 ステータス 要件
