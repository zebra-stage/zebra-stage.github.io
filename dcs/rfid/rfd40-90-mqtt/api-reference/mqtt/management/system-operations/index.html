Device Lifecycle

Two commands change what a reader is running. set_os downloads and installs firmware; reboot restarts the reader. Both reply with code 1 before the work is done:

  • set_os reports its outcome in alerts events with id: "FIRMWARE_UPDATE". While an update runs, the reader refuses other commands with code 4.
  • reboot reports no outcome event, and is refused during an inventory with code 5. The operating mode is lost on reboot.

See Update Firmware and Restart the Reader.

In This Section​

⬆️

set_os

An over-the-air firmware update from a .DAT image URL. Asynchronous.

🔁

reboot

A warm reset of the reader over the management endpoint.
