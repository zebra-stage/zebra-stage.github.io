Event Configuration​

cfgEventPayload​

The eventConfiguration object of config_events, and of an endpoint configuration. Every flag is a boolean. A flag marked reserved is accepted, stored, and returned in read-backs, but has no effect. The support status is as the API developer states it; the contract does not mark it.

No member is required.

Changes take effect after the reader reboots. Which configuration wins when config_events and an endpoint's eventConfiguration disagree is not specified in the available sources.

heartbeatConfiguration​

FieldTypeRequiredDefaultLimitsMeaning
intervalintegerNomax 65535Seconds between heartbeats
inventoryStatusbooleanNoInclude inventory status in each heartbeat
batteryStatusbooleanNoInclude battery status in each heartbeat
userAppsbooleanNoInclude user-application status in each heartbeat. Not supported: no heartbeat carries it.

alertThresholds​

The four threshold members of cfgEventPayload.

FieldTypeRequiredDefaultLimitsMeaning
cpuThresholdintegerNoCPU usage percentage above which an alert is raised. Reserved: accepted but has no effect.
ramThresholdintegerNoRAM usage percentage above which an alert is raised. Reserved: accepted but has no effect.
flashThresholdintegerNoFlash usage percentage above which an alert is raised. Reserved: accepted but has no effect.
temperatureThresholdintegerNoTemperature above which an alert is raised. Reserved: accepted but has no effect.
