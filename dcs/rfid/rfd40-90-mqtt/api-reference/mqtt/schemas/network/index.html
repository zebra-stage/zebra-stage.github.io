Network

Reference·Audience: API consumer·Use: look up the members, types and limits of a network object

These objects are sent with set_wifi and delete_wifi_profile, and returned by get_wifi and get_eth. Default is the value the reader uses when you omit the member. The procedures are in Configure Wi-Fi.

Wi-Fi Profile​

cfgWifiPayload​

The wifiConfig object of set_wifi.

FieldTypeRequiredDefaultLimitsMeaning
interfaceNamestringNoThe Wi-Fi interface, such as wlan0. When omitted, the reader uses its single Wi-Fi interface
enableInterfacebooleanNoWhether the interface is enabled. No default is documented
operationenum: CREATE, MODIFYYesCREATE for a new network, or MODIFY for one the reader already has
accessPointobject (wifiAccessPoint)YesThe profile's network, connection behavior, addressing and security

wifiAccessPoint​

FieldTypeRequiredDefaultLimitsMeaning
connectbooleanNotrue switches to this profile now; false only saves it
isPreferredbooleanYesWhether the reader always connects to this profile when it is available
autoConnbooleanNoReserved for backward compatibility; the contract states it will be removed
essidstringYesThe network name, which selects the profile
enableSecuritybooleanNoWhether the network is secured. true requires security. How an open-network profile is expressed is not confirmed
ipv4Configurationobject (ipv4Configuration)NoIPv4 addressing. The command's source states that static IPv4 and IPv6 are not available in the current API version
securityobject (wifiSecurity)NoThe security type and credentials. Required when enableSecurity is true
  • essid is required, and case-sensitive.
  • When enableSecurity is true, security must carry both securityType and the matching member of securityDetails.

wifiSecurity​

FieldTypeRequiredDefaultLimitsMeaning
securityTypewifiSecurityTypeYesThe network's security type, which selects the member of securityDetails
securityDetailsobjectYesThe credentials, in the one member named by securityType

wifiSecurityDetails​

Exactly one member, the one named by securityType, may be present.

FieldTypeRequiredDefaultLimitsMeaning
WPA2Personalobject (wpaPersonalCredentials)NoCredentials for WPA2-Personal
WPA3Personalobject (wpaPersonalCredentials)NoCredentials for WPA3-Personal
WPA2EnterpriseobjectNoCredentials for WPA2-Enterprise
WPA3EnterpriseobjectNoCredentials for WPA3-Enterprise

WPA2Enterprise and WPA3Enterprise carry the members of wpaEnterpriseCredentials, each with its own protocol values.

wpaPersonalCredentials​

FieldTypeRequiredDefaultLimitsMeaning
passwordstring (wpaPreSharedKey)YesThe pre-shared key, 8 to 63 characters

wpaEnterpriseCredentials​

FieldTypeRequiredDefaultLimitsMeaning
authenticationwifiEapMethodYesThe outer EAP method: tls, ttls or peap
innerAuthenticationwifiInnerEapMethodNoThe inner method. Omit it for tls; for ttls and peap it is mschapv2, the default
identitystringNoThe user name. Required for ttls and peap
anonymousIdentitystringNoThe outer identity sent before the tunnel is set up
passwordstringNoThe password, for ttls and peap
passphrasestringNoA passphrase. How it differs from password is not documented
certificatearray of certificateRefNoInstalled certificates, by component and name
protocolwpa2EnterpriseProtocol or wpa3EnterpriseProtocolNoThe cipher suite: WPA2_Enterprise_CCMP for WPA2, or one of five WPA3 values

certificate entries are certificateRef objects, at most four, one per component.

IPv4 Addressing​

ipv4Configuration​

FieldTypeRequiredDefaultLimitsMeaning
ipAddressstringNoThe IPv4 address
subnetMaskstringNoThe subnet mask, in dotted-quad form
gatewaystringNoThe default gateway
enableDhcpbooleanNoWhether DHCP assigns the address; when true, the other members are read-back values only
dnsServerstringNoThe DNS server; 0.0.0.0 means none is configured
domainNamestringNoThe network's domain name

Delete a Profile​

delWifiProfile​

The wifiProfileInfo object of delete_wifi_profile.

FieldTypeRequiredDefaultLimitsMeaning
essidstringYesThe network name of the profile to delete

Read-Backs​

wifiProfiles​

The wifiProfiles object of the get_wifi reply. When the Wi-Fi interface is disabled, the reply carries a single wifiConfig.interfaceDetails object instead.

FieldTypeRequiredDefaultLimitsMeaning
wifiConfigarray of wifiConfigResponseNoOne record per saved profile

Each record's interfaceDetails:

FieldTypeMeaning
interfaceNamestringThe Wi-Fi interface, such as wlan0
statusinterfaceEnableStateWhether the interface is enabled: Enabled or Disabled. The contract's own examples also show ENABLED and an empty string
hostnamestringThe reader's host name
macAddressstringThe interface's MAC address
accessPoint.essidstringThe profile's network name
accessPoint.statusconnectionStateCONNECTED when the reader has joined this network
accessPoint.securityTypewifiSecurityTypeThe profile's security type
accessPoint.isPreferredbooleanWhether the profile is preferred
accessPoint.autoConnbooleanReserved for backward compatibility; the contract states it will be removed
ipv4Configurationipv4ConfigurationThe addressing, on the connected profile
securityDetailswifiSecurityDetailsThe credentials, masked

ethConfigResponse​

The ethConfig object of the get_eth reply. When the interface is disabled, it carries only interfaceName and status.

FieldTypeMeaning
interfaceDetails.interfaceNamestringThe Ethernet interface, such as eth0
interfaceDetails.statusinterfaceEnableStateWhether the interface is enabled
interfaceDetails.hostnamestringThe reader's host name
interfaceDetails.macAddressstringThe interface's MAC address
interfaceDetails.linkStatus.statusconnectionStateWhether the physical link is up
interfaceDetails.linkStatus.linkSpeedstringThe link speed, as free text such as 100Mbps
interfaceDetails.ipv4Configurationipv4ConfigurationThe addressing
interfaceDetails.securityobject802.1X security details. Not populated in the current API version

The reader reports states in more than one letter case; compare without regard to case. The MQTT API has no command that changes Ethernet settings.
