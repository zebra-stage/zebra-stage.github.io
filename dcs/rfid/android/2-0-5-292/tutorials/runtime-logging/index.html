#overview Overview

This tutorial provides a comprehensive guide for developers to integrate, configure, and retrieve Runtime Logs from Zebra RFD40 and RFD90 RFID sled devices using the Zebra RFID SDK for Android.

Runtime logging enables developers to capture firmware diagnostics, communication events, reader state transitions, and error traces for troubleshooting, debugging, performance analysis, and enterprise support diagnostics.

#create-the-project Create the Project

  1. Create a new Android Studio project.
  2. Refer to the Hello RFID tutorial to prepare the RFID SDK environment.
  3. Connect to an RFD40 or RFD90 reader.
  4. Follow the Runtime Logging implementation described below.

#runtime-logging-ui Runtime Logging User Interface

The Logger Fragment in the Zebra RFID Demo Application provides controls to:

  • Enable SDK debug logging

#runtime-logging-architecture Runtime Logging Architecture

Index Functional Area Description
1 Application – Enable Debug Logs Enable or disable SDK debug logging.
2 Reader – Enable Real-Time Logs Configure reader logging verbosity.
3 Retrieve Logs Retrieve RAM and FLASH logs.
4 Export Logs Export logs to a file.

#application-debug-logs 1. Application – Enable Debug Logs

Enables or disables SDK-side debug logging. When enabled, SDK debug messages are written to Android Logcat using the 123RFID tag.

#sdk-api-usage SDK API Usage 


// Enable debug logs
logger.setLogConfig(
        LogStates.DEBUGLOGGERSTATE,
        true);

// Disable debug logs
logger.setLogConfig(
        LogStates.DEBUGLOGGERSTATE,
        false);

// Get current state
boolean enabled =
        logger.getLogConfig(
                LogStates.DEBUGLOGGERSTATE);
State Behavior
ON SDK debug messages are written to Logcat.
OFF SDK debug messages are suppressed.

#reader-enable-realtime-logs 2. Reader – Enable Real-Time Logs

Controls the real-time diagnostic log output streamed from the connected RFID reader.

#log-levels Supported Log Levels

Logging Level Description
None Real-time logging disabled.
Error Error messages only.
Warning Warning and Error messages.
Verbose All available log information.

#set-realtime-log setRfidRealTimeReaderLog() 


logger.setRfidRealTimeReaderLog(RealTimeLogsType.Verbose);
logger.setRfidRealTimeReaderLog(RealTimeLogsType.Warning);
logger.setRfidRealTimeReaderLog(RealTimeLogsType.Error);
logger.setRfidRealTimeReaderLog(RealTimeLogsType.None);

Method Signature


void setRfidRealTimeReaderLog(
        RealTimeLogsType realTimeLogsType)

Exceptions

  • InvalidUsageException
  • OperationFailureException
  • ADMIN_CONNECT_ERROR

Example


try {

    logger.setRfidRealTimeReaderLog(
            RealTimeLogsType.Verbose);

} catch (InvalidUsageException e) {

    Log.e(TAG,
          "Invalid parameter: "
          + e.getInfo());

} catch (OperationFailureException e) {

    Log.e(TAG,
          "Operation failed: "
          + e.getResults());
}

#retrieve-logs 3. Retrieve Logs

Retrieves historical logs stored in reader RAM and FLASH memory. 


try {

    rfidLogger.getRfidReaderLogs(
            LogStates.INTERNALRAMANDFLASHLOGSTATE,
            true);

} catch (InvalidUsageException e) {

    Log.d(TAG,
          "getRfidReaderLogs failed: "
          + e.getMessage());
}

Log Storage Types

Storage Description
RAM Volatile memory logs.
FLASH Persistent logs retained across reboots.

#export-logs 4. Export Logs

Exports retrieved logs to a text file on local device storage.

Scenario Behavior
Logs Retrieved Export file is created.
Logs Not Retrieved Prompt user to retrieve logs first. 

/sdcard/RfidLog.txt
