Impinj Gen2X APIs

RFID SDK for iOS 1.2.46

Applicable Devices : RFD 40, RFD 90 and 8500 devices

Compatible with iOS 17 and above

Overview

This page covers the Impinj Gen2X features available through the SDK: Protected Mode, Unprotected Mode, Enable Visibility, Disable Visibility, Tag Focus, Tag Quieting and Fast ID. These features require Impinj Gen2X tags and Gen2X-enabled Zebra RFID Readers.

Protected Mode

Protected mode is a feature that renders a tag invisible to an RFID reader unless the reader first provides the correct 32-bit PIN/Password. By default, the password is set to 0. Users can set the password using a tag write operation and retrieve it with a tag read operation.

This method attempts to place a specified RFID tag into its protected mode. In this mode, the tag will not be visible to a reader.


- (SRFID_RESULT)protectTag:(NSString*)tagID withTagData:(srfidTagData **)tagData   withPassword:(NSString*)password  aStatusMessage:(NSString**)statusMessage
{


    if (apiInstance != nil)
    {

        return [apiInstance srfidProtectTag:readerID aTagID:tagID aAccessTagData:tagData aPassword:password aStatusMessage:statusMessage];
    }

    return SRFID_RESULT_FAILURE;
}

Tag Focus

TagFocus allows readers to silence already-inventoried tags to reduce redundant reads, allowing a reader to focus on weak tags that are typically the last to be found. Set the boolean value to true to enable tag focus mode and false to disable it. if you try to disable the tag focus filter when it was not set. Tag focus mode targets tags inventoried in SESSION S1.


- (SRFID_RESULT)enableTagFocus:(BOOL)enableTagFocus aStatusMessage:(NSString**)statusMessage {

    if (apiInstance != nil)
    {
        return [apiInstance srfidSetTagFocus:readerID isTagFocusEnable:enableTagFocus aStatusMessage:statusMessage];

    }

    return SRFID_RESULT_FAILURE;
}

Tag Quieting

Tag quieting allows readers to silence already-inventoried tag subpopulations and thereby declutter complex enterprise tag environments. This technique is particularly suitable for applications that require reading the same tag multiple times as quickly as possible without the overhead of reading extraneous tags.

Tag quiet mask enums that are supported are:


typedef NS_ENUM(NSInteger, SRFID_ENUM_TAGQUIET_MASK) {

    ENUM_TAGQUIET_MASK_S0B,
    ENUM_TAGQUIET_MASK_S2B,
    ENUM_TAGQUIET_MASK_S3B,
    ENUM_TAGQUIET_MASK_SL_ASSERT,
    ENUM_TAGQUIET_MASK_S0A,
    ENUM_TAGQUIET_MASK_S2A,
    ENUM_TAGQUIET_MASK_S3A,
    ENUM_TAGQUIET_MASK_SL_DEASSERT,
    ENUM_TAGQUIET_MASK_UNKNOWN

};

The user can provide up to three valid combinations. Providing more than three combinations.For valid combination user cannot add enums with same session to SRFID_ENUM_TAGQUIET_MASK array.

Fast ID

FastID enables the impinj tags to backscatter their EPC and TID in a single response for inventory.


- (SRFID_RESULT) configureFastID:(BOOL)enableFastID status:(NSString **)statusMessage{

    if (apiInstance != nil)
    {

        return [apiInstance setFastID:readerID enable:enableFastID statusMessage:statusMessage];

    }

    return SRFID_RESULT_FAILURE;

}
