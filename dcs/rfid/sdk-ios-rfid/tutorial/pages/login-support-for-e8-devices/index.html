Login Support for E8 Devices

RFID SDK for iOS 1.2.46

Applicable Devices : RFD40, RFD90 (EU RED devices)

Compatible with iOS 17 and above

Overview

E8 devices are the EU SKU of the RFD40 and RFD90. They support an administrator login, which protects some reader settings and functions. This page shows how to log in as administrator and how to change the administrator password. Both calls are made on the SDK instance (apiInstance) for a connected reader (readerID), after the ASCII connection is established.

Use srfidAdminLogin to log in as administrator and srfidChangePassword to change the administrator password.

Admin Login

The srfidAdminLogin method logs in to an RFID reader as administrator. Pass the reader ID and the administrator password. Replace the placeholder with the password set on your reader.


- (void)adminLogin {
    NSString *statusMessage = nil;
    SRFID_RESULT result = [apiInstance srfidAdminLogin:readerID
                                              password:@"<your admin password>"
                                        aStatusMessage:&statusMessage];
    if (result == SRFID_RESULT_SUCCESS) {
        NSLog(@"Admin login succeeded");
    } else {
        NSLog(@"Admin login failed: %d %@", result, statusMessage);
    }
}

Change Password

The srfidChangePassword method changes the administrator password of an RFID reader. Pass the current password, the new password, and the new password again. The current password must be the one set on the reader. Otherwise the reader answers with "Password mismatch error".


- (void)changePassword {
    NSString *statusMessage = nil;
    SRFID_RESULT result = [apiInstance srfidChangePassword:readerID
                                               oldPassword:@"<your current admin password>"
                                             andNewPassword:@"<your new admin password>"
                                        andreEnterPassword:@"<your new admin password>"
                                            aStatusMessage:&statusMessage];
    if (result == SRFID_RESULT_SUCCESS) {
        NSLog(@"Change password succeeded");
    } else {
        NSLog(@"Change password failed: %d %@", result, statusMessage);
    }
}

Keep the new password safe. Some reader functions, such as getting the reader log, need an administrator login.
