About RFID SDK for iOS

RFID SDK for iOS 1.2.46

Overview

iOS RFID SDK is an API that an iOS developer can use to develop applications that uses Motorola/Zebra Bluetooth RFID readers. API is capable of managing readers and receives RFID data. API is provided as an "XCFramework" and there is a Demo application that a developer can refer on how to use that XCFramework.

Supported Devices

  • RFD4051 NEW
  • RFD40
  • RFD90
  • RFD40 Premium Plus
  • RFD40 Premium
  • RFD8500 RFID Reader
  • RFD8500 ASIC

iOS Versions

  • iOS 17 and above

What's New in 1.2.46

Device Support

RFID SDK 1.2.46 adds support for RFD40, RFD90 and RFD8500

  • Pre-filters: add individual/array pre-filters, delete a specific pre-filter, delete all pre-filters (RFD8500: up to 4 pre-filters; RFD40 and RFD90: up to 32)
  • Logging and Diagnostics: get reader logs, stream real-time logs, set log configs, adjust log levels
  • Access Sequence: delete operation, stop sequence, maximum operation limits, sequence execution, last access results retrieval, tag read
  • Error diagnostics via Get Last Error Info
  • Bluetooth Discovery settings: Bluetooth Discovery Enable/Disable, Beep on Reconnect, Reconnect Attempts

RFID SDK 1.2.46 adds support for RFD40 and RFD90

  • Cradle status query
  • Get/set reader friendly name

RFID SDK 1.2.46 adds support for RFD40 Premium, RFD40 Premium Plus and RFD90

  • Channel List API (Network IP and Wi-Fi)
