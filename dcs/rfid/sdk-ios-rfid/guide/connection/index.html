Connection and Disconnection

RFID SDK for iOS 1.2.46

Overview

This guide gives the steps to connect to and disconnect from an RFID reader using the RFID SDK for iOS. Connection is the first step to talk to a reader. Each step links to its tutorial page for the full detail.

Applicable Devices: RFD40, RFD90, RFD8500

Connect to a reader

The reader must be paired with the iOS device before you start.

1. Import the framework

#import <ZebraRfidSdkFramework/ZebraRfidSdkFramework.h>

2. Create the SDK instance

Every call goes through one SDK object, created once. See Creating the SDK Instance.

id<srfidISdkApi> apiInstance;
int readerID;

- (void)createSdkInstance {
    apiInstance = [srfidSdkFactory createRfidSdkApiInstance];
}

3. Register the delegate and subscribe for events

The SDK reports connection events to your delegate. Create an object that implements srfidISdkApiDelegate, register it and subscribe to the connection events. See Implement srfidISdkApiDelegate.

[apiInstance srfidSetDelegate:self];

int mask = SRFID_EVENT_READER_APPEARANCE | SRFID_EVENT_READER_DISAPPEARANCE |
           SRFID_EVENT_SESSION_ESTABLISHMENT | SRFID_EVENT_SESSION_TERMINATION;
[apiInstance srfidSubsribeForEvents:mask];

4. Set the operation mode and enable readers detection

Choose which kind of Bluetooth readers the SDK talks to, then let it detect readers that appear and disappear. See Set Operation Mode and Enable Available Readers Detection.

[apiInstance srfidSetOperationalMode:SRFID_OPMODE_MFI];
[apiInstance srfidEnableAvailableReadersDetection:YES];

5. Get the available readers

Each reader gets a reader ID. Keep the ID of the reader you want to use, because every later call passes it. See Get Available Readers.

NSMutableArray *available_readers = [[NSMutableArray alloc] init];
NSMutableArray *active_readers = [[NSMutableArray alloc] init];
[apiInstance srfidGetAvailableReadersList:&available_readers];
[apiInstance srfidGetActiveReadersList:&active_readers];

for (srfidReaderInfo *info in available_readers) {
    NSLog(@"Reader ID = %d name = %@", [info getReaderID], [info getReaderName]);
    readerID = [info getReaderID];
}

6. Establish the communication session

The call only starts the connection. See Connect.

SRFID_RESULT result = [apiInstance srfidEstablishCommunicationSession:readerID];
if (SRFID_RESULT_SUCCESS != result) {
    NSLog(@"Could not connect to reader %d", readerID);
}

7. Wait for the session event and establish the ASCII connection

The SDK reports that the session is open through srfidEventCommunicationSessionEstablished: of your delegate. Commands to the reader (software version, capabilities and so on) work only after the ASCII connection is established.

- (void)srfidEventCommunicationSessionEstablished:(srfidReaderInfo *)activeReader {
    NSLog(@"Reader Connected");
    readerID = [activeReader getReaderID];
    SRFID_RESULT ascii_result = [apiInstance srfidEstablishAsciiConnection:readerID];
    NSLog(@"ASCII connection result: %d", ascii_result);
}

Disconnect from a reader

Pass the reader ID of the connected reader. See Disconnect.

SRFID_RESULT result = [apiInstance srfidTerminateCommunicationSession:readerID];
if (SRFID_RESULT_SUCCESS != result) {
    NSLog(@"Could not disconnect from reader %d", readerID);
}

The SDK reports that the session is closed through srfidEventCommunicationSessionTerminated: of your delegate. Do not send further commands to that reader after it.

- (void)srfidEventCommunicationSessionTerminated:(int)readerID {
    NSLog(@"Reader Disconnected");
}

Special Connection Handling Cases

Automatic session reestablishment

When this option is on, the SDK reconnects by itself to the last active reader that disappeared unexpectedly, as soon as that reader is available again. See Enable Automatic Communication Session Reestablishment.

[apiInstance srfidEnableAutomaticSessionReestablishment:YES];
