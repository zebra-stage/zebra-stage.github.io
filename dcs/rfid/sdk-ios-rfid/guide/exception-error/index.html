Exception and error handling

RFID SDK for iOS 1.2.46

Overview

This guide gives details about error handling with the RFID SDK for iOS. The SDK does not throw exceptions. Each API call returns an SRFID_RESULT code, and many calls also return a status message.

Applicable Devices: RFD40, RFD90, RFD8500

Details

These are the values of SRFID_RESULT:

ResultMeaning
SRFID_RESULT_SUCCESSThe request was carried out.
SRFID_RESULT_FAILUREThe request failed. A general failure.
SRFID_RESULT_READER_NOT_AVAILABLEThe reader with the given reader ID is not available.
SRFID_RESULT_INVALID_PARAMSA parameter passed to the call is not valid.
SRFID_RESULT_RESPONSE_TIMEOUTThe reader did not answer in time.
SRFID_RESULT_NOT_SUPPORTEDThe request is not supported.
SRFID_RESULT_RESPONSE_ERRORThe reader answered with an error. The reason is in statusMessage.
SRFID_RESULT_WRONG_ASCII_PASSWORDThe ASCII connection password is wrong.
SRFID_RESULT_ASCII_CONNECTION_REQUIREDThe request needs an ASCII connection to the reader.

Error Handling

Check the return value of every API call. When the result is SRFID_RESULT_RESPONSE_ERROR, read the status message that the call filled in. This example shows the pattern the tutorial pages use:

NSString *error_response = nil;

SRFID_RESULT result = [apiInstance srfidGetAntennaConfiguration:readerID
                                          aAntennaConfiguration:&antenna_cfg
                                                  aStatusMessage:&error_response];
if (SRFID_RESULT_SUCCESS == result) {
    // The request succeeded
} else if (SRFID_RESULT_RESPONSE_ERROR == result) {
    NSLog(@"Error response from RFID reader: %@", error_response);
} else if (SRFID_RESULT_RESPONSE_TIMEOUT == result) {
    NSLog(@"Timeout occurred");
} else if (SRFID_RESULT_READER_NOT_AVAILABLE == result) {
    NSLog(@"RFID reader with id = %d is not available", readerID);
} else {
    NSLog(@"Request failed");
}

Operation results

A request can succeed while the operation on the tag fails. For tag read and write, a SRFID_RESULT_SUCCESS result means the request was processed. Then check getOperationSucceed on the returned srfidTagData object, and read getOperationStatus for the reason when it is NO.

if (SRFID_RESULT_SUCCESS == result) {
    if (NO == [access_result getOperationSucceed]) {
        NSLog(@"Operation has failed with error: %@", [access_result getOperationStatus]);
    }
}
