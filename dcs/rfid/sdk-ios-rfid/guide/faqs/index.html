Questions and Answers

RFID SDK for iOS 1.2.46

Overview

This guide gives answers to frequently asked questions about RFID operations and the use of the RFID SDK for iOS.

Applicable Devices: RFD40, RFD90, RFD8500

Get Version Information

Q. How to get the version information of the reader?

Use srfidGetReaderVersionInfo. It returns the device (firmware), NGE and Bluetooth versions of the reader.

srfidReaderVersionInfo *version_info = [[srfidReaderVersionInfo alloc] init];
NSString *error_response = nil;

SRFID_RESULT result = [apiInstance srfidGetReaderVersionInfo:readerID
                                           aReaderVersionInfo:&version_info
                                               aStatusMessage:&error_response];
if (SRFID_RESULT_SUCCESS == result) {
    NSLog(@"Device version: %@", [version_info getDeviceVersion]);
    NSLog(@"NGE version: %@", [version_info getNGEVersion]);
    NSLog(@"Bluetooth version: %@", [version_info getBluetoothVersion]);
}

See Knowing the Software Version.

Access criteria

Q. How to use access criteria?

The access criteria select the tag that an operation is applied to. For an example, see Select the tag in the Gen 2 v2 features guide.

Pre-filter

Q. How to read a single tag using its EPC?

Use pre-filters. They are the same as the select command of the C1G2 specification, and when they are configured, they are applied before inventory operations. See Pre-filters Configuration and Inventory with Pre-filters.
