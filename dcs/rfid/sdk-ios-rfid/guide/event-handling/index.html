Event Handling

RFID SDK for iOS 1.2.46

Overview

The SDK reports what the reader does through asynchronous notifications, such as a tag read, a trigger press or a connection change. This guide shows how to receive them in your app.

Applicable Devices: RFD40, RFD90, RFD8500

Details

You register one object as the delegate of the SDK and subscribe to the types of events you want. The SDK calls the matching method of your delegate only for the event types you subscribed to. Events you did not subscribe to are not delivered.

Setting it up

1. Create an object that implements srfidISdkApiDelegate

See Implement srfidISdkApiDelegate for the full class with all the delegate methods.

@interface ViewController : UIViewController<srfidISdkApiDelegate>
@end

2. Register the object as the notification receiver

[apiInstance srfidSetDelegate:self];

3. Subscribe for the event types you need

Combine the masks of the events you want with |. You can call srfidSubsribeForEvents more than once.

int mask = SRFID_EVENT_READER_APPEARANCE | SRFID_EVENT_READER_DISAPPEARANCE |
           SRFID_EVENT_SESSION_ESTABLISHMENT | SRFID_EVENT_SESSION_TERMINATION;
[apiInstance srfidSubsribeForEvents:mask];
[apiInstance srfidSubsribeForEvents:(SRFID_EVENT_MASK_READ | SRFID_EVENT_MASK_STATUS)];

Receiving a tag read

The SDK calls srfidEventReadNotify: for each tag received from the reader. See Inventory.

- (void)srfidEventReadNotify:(int)readerID aTagData:(srfidTagData *)tagData {
    NSLog(@"Tag data received from RFID reader with ID = %d", readerID);
    NSLog(@"Tag id: %@", [tagData getTagId]);
}

Receiving a battery event

The SDK calls srfidEventBatteryNotity: when the reader sends a battery status event. See Knowing Battery Status.

- (void)srfidEventBatteryNotity:(int)readerID aBatteryEvent:(srfidBatteryEvent *)batteryEvent {
    NSLog(@"Battery level: %d", [batteryEvent getPowerLevel]);
    NSLog(@"Charging: %@", ((NO == [batteryEvent getIsCharging]) ? @"NO" : @"YES"));
}
