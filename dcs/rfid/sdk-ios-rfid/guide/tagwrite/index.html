TAG Write Operation Guide

RFID SDK for iOS 1.2.46

Overview

This guide describes how to write data to a tag with the RFID SDK for iOS: what to prepare on the reader, how to write, and how to check the result.

Applicable Devices: RFD40, RFD90, RFD8500

General Steps

This is the general sequence to write to a tag:

  1. Set the antenna output power. Power is in 0.1 dBm units.
  2. Set the singulation control settings.
  3. Optionally, add pre-filters so that the reader selects only the tags you want, and enable their use in the antenna configuration.
  4. Get the EPC of the tag to write, for example from an inventory.
  5. Write the data with srfidWriteTag, or with srfidWriteTagAsync.
  6. Check the result of the request and the result of the write operation.

Setting it up

1. Set the antenna power

The output power is set with srfidSetAntennaConfiguration and is in 0.1 dBm units. For example, 200 is 20.0 dBm. The lowest and highest power the reader supports come from srfidGetReaderCapabilitiesInfo (getMinPower and getMaxPower). The antenna configuration also holds the link profile and the Tari. If you only want to change the power, read the current configuration first and set the power on it.

srfidAntennaConfiguration *antenna_cfg = [[srfidAntennaConfiguration alloc] init];
NSString *error_response = nil;

SRFID_RESULT result = [apiInstance srfidGetAntennaConfiguration:readerID
                                          aAntennaConfiguration:&antenna_cfg
                                                  aStatusMessage:&error_response];
if (SRFID_RESULT_SUCCESS == result) {
    /* 200 = 20.0 dBm */
    [antenna_cfg setPower:200];
    result = [apiInstance srfidSetAntennaConfiguration:readerID
                                 aAntennaConfiguration:antenna_cfg
                                         aStatusMessage:&error_response];
}

See Antenna Configuration.

2. Set the singulation control

The singulation control settings are the session, the tag population, the SL flag and the inventory state. Set them with srfidSetSingulationConfiguration.

srfidSingulationConfig *singulation_cfg = [[srfidSingulationConfig alloc] init];
[singulation_cfg setTagPopulation:30];
[singulation_cfg setSession:SRFID_SESSION_S0];
[singulation_cfg setSlFlag:SRFID_SLFLAG_ASSERTED];
[singulation_cfg setInventoryState:SRFID_INVENTORYSTATE_A];

result = [apiInstance srfidSetSingulationConfiguration:readerID
                                    aSingulationConfig:singulation_cfg
                                        aStatusMessage:&error_response];

See Singulation Configuration.

3. Use pre-filters (optional)

Pre-filters are the same as the select command of the C1G2 specification. When they are configured and enabled in the antenna configuration (setDoSelect:YES), they are applied before inventory operations. A reader holds up to 4 pre-filters on the RFD8500 and up to 32 on the RFD40 and RFD90.

See Pre-filters Configuration, Add Pre-filters Array and Inventory with Pre-filters.

Writing a tag

A tag is addressed by its EPC, as a hexadecimal string. The data to write is also a hexadecimal string, with four characters per 16-bit word. Write to a memory bank at an offset in words.

In the EPC memory bank, word 0 is the CRC and word 1 is the PC. The EPC starts at word 2. To replace a 96-bit EPC, write 24 hexadecimal characters at offset 2. Do not write the EPC at offset 0, because that overwrites the CRC and PC words.

After the write, the tag answers to its new EPC. Use the new EPC to address it again.

srfidTagData *access_result = [[srfidTagData alloc] init];
NSString *tag_id = @"E28011B0A506007D3DD17A34";
NSString *data = @"ABCDEF0123456789ABCDEF01";
NSString *error_response = nil;

SRFID_RESULT result = [apiInstance srfidWriteTag:readerID
                                          aTagID:tag_id
                                  aAccessTagData:&access_result
                                     aMemoryBank:SRFID_MEMORYBANK_EPC
                                         aOffset:2
                                           aData:data
                                       aPassword:0x00
                                   aDoBlockWrite:NO
                                  aStatusMessage:&error_response];

See Read and Write.

Asynchronous write

srfidWriteTagAsync takes the same parameters as srfidWriteTag. When you use the asynchronous read or write, stop the running inventory first with srfidStopInventory. See Async Tag Read and Write.

Checking the result

Check two results. The return value says whether the request reached the reader. getOperationSucceed on the returned srfidTagData says whether the write itself worked, and getOperationStatus gives the reason when it failed.

if (SRFID_RESULT_SUCCESS == result) {
    if (NO == [access_result getOperationSucceed]) {
        NSLog(@"Write operation has failed with error: %@", [access_result getOperationStatus]);
    }
} else if (SRFID_RESULT_RESPONSE_ERROR == result) {
    NSLog(@"Error response from RFID reader: %@", error_response);
} else if (SRFID_RESULT_RESPONSE_TIMEOUT == result) {
    NSLog(@"Timeout occurred");
} else {
    NSLog(@"Request failed");
}
