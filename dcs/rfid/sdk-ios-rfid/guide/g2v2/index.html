Gen 2 v2 features

RFID SDK for iOS 1.2.46

Overview

This guide gives details about the Gen2V2 untraceable operation with the RFID SDK for iOS.

Applicable Devices: RFD40, RFD90, RFD8500

Details

The untraceable operation sets the untraceable configuration of a tag, which controls which parts of the tag are hidden from readers. It is done with srfidUntraceable.

Untraceable

1. Select the tag

The access criteria select the tag that the operation is applied to.

srfidAccessCriteria *accessCriteria = [[srfidAccessCriteria alloc] init];

srfidTagFilter *tagFilter1 = [[srfidTagFilter alloc] init];
[tagFilter1 setFilterMaskBank:SRFID_MEMORYBANK_EPC];
[tagFilter1 setFilterData:@"0176"];
[tagFilter1 setFilterDoMatch:YES];
[tagFilter1 setFilterMask:@"FFFF"];
[tagFilter1 setFilterMaskStartPos:2];
[tagFilter1 setFilterMatchLength:1];

[accessCriteria setTagFilter1:tagFilter1];

2. Set the untraceable configuration

The password is the access password of the tag, as a hexadecimal value. In this example the EPC is hidden, and the user memory and the TID are shown.

srfidUntraceableConfig *untraceConfig = [[srfidUntraceableConfig alloc] init];
NSString *status = nil;

[untraceConfig setShowEpc:NO];
[untraceConfig setEpcLen:2];
[untraceConfig setShowUser:YES];
[untraceConfig setTid:SRFID_TID_SHOW];

SRFID_RESULT result = [apiInstance srfidUntraceable:readerID
                                    aAccessCriteria:accessCriteria
                                      aAccessConfig:nil
                                          aPassword:0x00000001
                                 aUntraceableConfig:untraceConfig
                                     aStatusMessage:&status];
if (SRFID_RESULT_SUCCESS == result) {
    NSLog(@"Set Untraceable Success");
} else {
    NSLog(@"Failed to set untraceable");
}
