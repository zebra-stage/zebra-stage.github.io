Setting up Region

RFID SDK for iOS 1.2.46

Overview

This guide gives the steps to set the region a reader operates in using the RFID SDK for iOS. A reader must have a region set before it can do RFID operations.

Applicable Devices: RFD40, RFD90, RFD8500

Regulatory Configuration

The SDK manages the regulatory parameters of an active reader. The regulatory configuration includes:

  • The code of the selected region
  • Hopping
  • The set of enabled channels

The set of enabled channels includes only channels that are supported in the selected region. If hopping cannot be configured for the selected region, do not specify the enabled channels.

Read and write the regulatory parameters with srfidGetRegulatoryConfig and srfidSetRegulatoryConfig. See Regulatory Configuration. The supported regions and the details of a region come from srfidGetSupportedRegions and srfidGetRegionInfo. See Knowing Supported Regions.

Setting the regulatory

This is the general sequence to set the region:

  1. Get the supported regions.
  2. Choose the region to operate in from the list.
  3. Get the details of that region: its supported channels and whether hopping can be configured.
  4. Set the region with the hopping and the set of channels it needs.
  5. If your app cached the antenna power level or the link profiles, read them again after you change the region.

1. Get the supported regions

NSMutableArray *regions = [[NSMutableArray alloc] init];
NSString *error_response = nil;

SRFID_RESULT result = [apiInstance srfidGetSupportedRegions:readerID
                                          aSupportedRegions:&regions
                                              aStatusMessage:&error_response];
if (SRFID_RESULT_SUCCESS == result) {
    for (srfidRegionInfo *info in regions) {
        NSLog(@"Region [%@] code: %@", [info getRegionName], [info getRegionCode]);
    }
}

2. Get the details of the region

NSMutableArray *supported_channels = [[NSMutableArray alloc] init];
BOOL hopping_configurable = NO;

result = [apiInstance srfidGetRegionInfo:readerID
                             aRegionCode:region_code
                      aSupportedChannels:&supported_channels
                    aHoppingConfigurable:&hopping_configurable
                           aStatusMessage:&error_response];

3. Set the region

If the region allows hopping to be configured, enable hopping and the channels you want. Otherwise use SRFID_HOPPINGCONFIG_DEFAULT and no channels.

srfidRegulatoryConfig *regulatory_cfg = [[srfidRegulatoryConfig alloc] init];
[regulatory_cfg setRegionCode:region_code];
[regulatory_cfg setEnabledChannelsList:enabled_channels];
[regulatory_cfg setHoppingConfig:hopping_on];

result = [apiInstance srfidSetRegulatoryConfig:readerID
                             aRegulatoryConfig:regulatory_cfg
                                 aStatusMessage:&error_response];
if (SRFID_RESULT_SUCCESS == result) {
    NSLog(@"Regulatory configuration has been set");
} else if (SRFID_RESULT_RESPONSE_ERROR == result) {
    NSLog(@"Error response from RFID reader: %@", error_response);
}

Region Is Not Configured

When no region is set, srfidGetRegulatoryConfig returns the region code NA. In that case set the region before you perform any operation.

srfidRegulatoryConfig *regulatory_cfg = [[srfidRegulatoryConfig alloc] init];
SRFID_RESULT result = [apiInstance srfidGetRegulatoryConfig:readerID
                                          aRegulatoryConfig:&regulatory_cfg
                                              aStatusMessage:&error_response];
if (SRFID_RESULT_SUCCESS == result &&
    NSOrderedSame == [[regulatory_cfg getRegionCode] caseInsensitiveCompare:@"NA"]) {
    // Set the regulatory configuration (see Setting the regulatory)
}

Note: Admin login is required for devices under EU RED compliance EU-RED-Countries.
