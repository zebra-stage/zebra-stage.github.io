APIs

HID SDK 1.0

Overview

This guide provides the APIs offered by the HID SDK to manage communication with the device‘s secure element (HID SE), validate contactless HID credentials (such as SEOS, Desfire etc.), and retrieve authenticated data, including Physical Access Control System (PACS) information.

Main Components

The HID SDK architecture consists of the following primary components:

  • HidSdkManager: The primary class and interface to the HID Dispatcher - the background service that manages and directs data transmissions between the HID Secure Element, the NFC stack, and physical contactless HID smart cards. HidSdkManager manages all interactions with the HID service and provides methods for credential interactions.
  • Callback Interfaces: A set of interfaces used to handle asynchronous operations.
    • ConnectionCallback: Monitors the connection status to the underlying HID service.
    • HidInitializationCallback: Reports the result of the secure element initialization.
    • HidResponseCallback: Delivers the data or errors from card operations.
  • Data Models: Parcelable classes that encapsulate data returned from the SDK.
    • SEInfo: Contains information about the secure element status after initialization.
    • SEResponse: Contains data read from an NFC card, such as its UID and PACS data.
    • HidSdkUtils: A utility class with helper methods for converting data between byte arrays and hexadecimal strings.

HidSdkManager

This is the main entry point for all SDK operations. It manages the service connection and provides methods for card interactions.

Package: com.zebra.hid.sdk.HidSdkManager

Constructor

    public HidSdkManager(Context context, ConnectionCallback callback)

Description: Creates an SDK instance and automatically binds to the background HID service.

Methods

    public void initiateHIDCommunication(HidInitializationCallback callback)

Description: Initializes communication with the secure element.

isCardHID(Tag tag, HidResponseCallback callback)

    public void isCardHID(Tag tag, HidResponseCallback callback)

Description: Checks if a detected NFC tag is a valid HID card.

getAuthenticatedData(Tag tag, HidResponseCallback callback)

    public void getAuthenticatedData(Tag tag, HidResponseCallback callback)

Description: Reads authenticated data from a valid HID card, including PACS data, serial number, and other card information.

getVersion(HidResponseCallback callback)

    public void getVersion(HidResponseCallback callback)

Description: Retrieves the version of the HID SDK.

getFirmwareVersion(HidResponseCallback callback)

    public void getFirmwareVersion(HidResponseCallback callback)

Description: Retrieves the firmware version of the secure element.

isServiceBound()

    public boolean isServiceBound()

Description: Checks if the SDK is currently bound to the HID service and ready for operations.

reconnect()

    public void reconnect()

Description: If not bound, it starts a new bind. The result arrives asynchronously as onConnected() or ConnectionCallback.onError. If already bound, it does nothing. It is meant to be used in onResume(). Since reconnect() does not re-run initiateHIDCommunication(), it must be called again after onConnected().

disconnect()

    public void disconnect()

Description: Unbinds and executes onDisconnected(). This is meant to be used in onPause().It does not shut down the SDK's worker threads.

cleanup()

    public void cleanup()

Description: Releases all SDK resources and unbinds from the HID service. Should be called in the Activity‘s onDestroy().

Description: Called when the SDK successfully connects to the HID service.

    void onDisconnected()

Description: Called when the SDK disconnects from the HID service.

onError(String error)

    void onError(String error)

Description: Called when a connection error occurs.

Errors:

  • "Failed to initiate service binding” - Android could not start the bind (e.g. service component not found/exported, or the OS rejected the request).
  • "Failed to bind to service: " + e.getMessage() - This could be due to a SecurityException if the caller lacks permission to bind to com.zebra.hidservice.HidService.

Data Models & Utilities

SEInfo

Description: Returns the raw status code of the secure element initialization.

getSak()

    byte getSak()

Description: Returns the SAK (Select Acknowledge from HID Secure Element) byte from the protocol. TDA slot ID expected value 0x20.

getStatusMsg()

    String getStatusMsg()

Description: Returns a human-readable message describing the initialization status.
