Provisioning

HID SDK 1.0

Overview

To authorize an application to use the HID service (com.zebra.hidservice), create and deploy a security profile using Zebra’s StageNow tool. This process grants your application, identified by its unique signature, the necessary permissions to communicate with the HID service on the device.

Prerequisites

  • The release-signed application APK file
  • A host computer with Java (JDK/JRE) installed.
  • Zebra’s StageNow tool installed on the host computer.

I. Extract Application Signature Certificate

Generate the certificate file to be used for the StageNow profile.

  1. Download the Zebra SigTools utility.

  2. Extract the contents of the zip file to a working directory on the host computer, including the "ZebraSigTools_1.5.jar" file.

  3. Open a command prompt or terminal and navigate to the directory where the .zip file contents are extracted.

  4. Place your application's release-signed APK file (e.g., app-release.apk) in the same directory.

  5. Execute the following Java command to extract the signature into a .crt certificate file:

    java -jar ZebraSigTools_1.5.jar getcert -inform apk -outform der -in <your-apk-file.apk> -outfile <your-certificate-name.crt>

Example: java -jar ZebraSigTools_1.5.jar getcert -inform apk -outform der -in app-release.apk -outfile HID_demo_launcher.crt

  1. A new certificate file (e.g., HID_demo_launcher.crt) is created in the directory. This file contains the signature required by StageNow.

II. Create a StageNow Profile & Staging Barcode

Create the StageNow profile and staging barcode to grant the application access to the HID service.

  1. Launch the StageNow application on the host computer.
  2. From the home screen, select Create new Profile.
  3. Choose the target MX Version for your devices from the dropdown menu (e.g., the latest available version).
  4. Select Xpert Mode and click Create.
  5. Enter a descriptive name for the profile (e.g., “HID Service Access Grant”) and click Start.
  6. In the “ADD/EDIT” window, locate AccessMgr and click the (+) button to add it to the profile. Click Add.
  7. Configure the AccessMgr settings with the following specific values and click Continue:
    • Service Access Action: Allow Caller to Call Service
    • Service Identifier: delegation-zebra-HID-api-access-control
    • Caller Package Name: [Enter your application's package name (e.g., com.zebra.hidDemoApp).]
    • Caller Signature: [Click the three-dot button (…) and browse to select the .crt certificate file generated in Step I.]
         
  8. Review the profile settings. Click Complete Profile.

III. Provision Devices

Use one of the following methods based on the desired tool to deploy the profile to the devices and authorize application access the HID service:

  • StageNow: Generate the barcode from the StageNow profile. Open StageNow client on the device and scan the barcode.
  • EMM: Export the StageNow XML file from the StageNow installation. Send the XML using either OEMConfig or MX.
