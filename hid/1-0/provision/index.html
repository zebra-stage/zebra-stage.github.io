Provisioning

HID SDK 1.0

Overview

This guide provides instructions for administrators, system integrators, and security engineers to configure, provision, and manage Zebra mobile computers equipped with embedded HID Physical Access Control System (PACS) technology.

Complete device provisioning consists of two operational procedures:

  • Application Authorization (Staging): Authorize client applications to bind to and communicate with the on-device HID service (com.zebra.hidservice) using Zebra StageNow and AccessMgr.
  • Hardware Key Provisioning (Manual): Inject proprietary HID Elite cryptographic keys into the hardware-backed Secure Element (SE) using physical provisioning cards.

Phase 1: Application Authorization

Applications must be authorized to use the HID service (com.zebra.hidservice). Create and deploy a security profile using Zebra’s StageNow tool to grant the application, identified by its unique signature, the necessary permissions to communicate with the HID service on the device.

I. Extract Application Signature: Extract the application's public signing certificate using the ZebraSigTools utility.
II. Create Profile & Generate Deployment Barcode or XML: Build an AccessMgr authorization profile within StageNow. Generate the staging barcode or XML containing the granted delegation rules.
III. Deploy to Devices: Scan the deployment barcode on the target device or deploy the XML via EMM.

Prerequisites

  • Release-signed application .APK file
  • Host computer with Java Runtime Environment (JRE) or Java Development Kit (JDK) installed
  • Zebra’s StageNow tool installed on the host computer.

I. Extract Application Signature

Generate the certificate file to be used for the StageNow profile.

  1. Download the Zebra SigTools utility.

  2. Extract the contents of the zip file to a working directory on the host computer, including the "ZebraSigTools_1.5.jar" file.

  3. Open a command prompt or terminal and navigate to the directory where the .zip file contents are extracted.

  4. Place your application's release-signed APK file (e.g., app-release.apk) in the same directory.

  5. Execute the following Java command to extract the signature into a .crt certificate file:

    java -jar ZebraSigTools_1.5.jar getcert -inform apk -outform der -in <your-apk-file.apk> -outfile <your-certificate-name.crt>

    Example:

    java -jar ZebraSigTools_1.5.jar getcert -inform apk -outform der -in app-release.apk -outfile HID_demo_launcher.crt

  6. A new certificate file (e.g., HID_demo_launcher.crt) is created in the directory. This file contains the signature required by StageNow.

II. Create Profile & Generate Barcode or XML

Create the StageNow profile and staging barcode to grant the application access to the HID service.

  1. Launch the StageNow application on the host computer.
  2. From the home screen, select Create new Profile.
  3. Choose the target MX Version for your devices from the dropdown menu (e.g., the latest available version).
  4. Select Xpert Mode and click Create.
  5. Enter a descriptive name for the profile (e.g., “HID Service Access Grant”) and click Start.
  6. In the “ADD/EDIT” window, locate AccessMgr and click the (+) button to add it to the profile. Click Add.
  7. Configure the AccessMgr settings with the following specific values and click Continue:
    • Service Access Action: Allow Caller to Call Service
    • Service Identifier: delegation-zebra-HID-api-access-control
    • Caller Package Name: [Enter your application's package name (e.g., com.zebra.hidDemoApp).]
    • Caller Signature: [Click the three-dot button (…) and browse to select the .crt certificate file generated in Step I.]
            
  8. Review the profile settings. Click Complete Profile.

III. Deploy to Devices

Use one of the following methods based on the desired tool to deploy the profile to the devices and authorize application access the HID service:

  • StageNow: Generate the barcode from the StageNow profile. Open StageNow client on the device and scan the barcode.
  • EMM: Export the StageNow XML file from the StageNow installation. Send the XML using either OEMConfig or MX.

Phase 2: Hardware Key Provisioning

Once client applications are authorized to communicate with the service, configure the internal Secure Element with your organization's custom HID Elite Keys.

All physical provisioning cards must be procured directly from HID Global Corporation referencing your organization's unique HID Elite Program Number. Zebra does not generate or store customer Elite keys. Visit "hidglobal.com" or contact the designated HID Global sales representative for Elite Program registration, custom key enrollment, and provisioning card ordering.

When submitting an order to HID Global, specify your organization’s HID Elite Program Number and request the appropriate card sets:

  • Manual Elite Provisioning Set: Card P000 (Reader Configuration) and Card P001 (Elite Credential / Key Injection).
  • Factory Rollback Set: Card P002 (Elite Downgrade Card) and Card P003 (Standard Key Reset Card).

Requirements

  • Install the Zebra HID Provisioning Application. Available from the Zebra Support portal.
  • Install the application .APK onto target devices. Use Zebra StageNow or an EMM.
  • Native Android NFC is enabled. In Settings > Connected devices > Connection preferences, toggle NFC to ON.
  • Device battery level is at least 30% or higher. This prevents interruptions during write cycles.
  • Third-party rugged cases or accessories containing metal shielding is removed to avoid interference.
  • Authorize the target application.

Card Sequence Logic

Manual Elite provisioning relies on a two-step cryptographic handshake in a specific sequence:

Step Card Card Role / Name Cryptographic Function
1 P000 Elite Credential / Administrator Key Card Enclave Initialization: Authenticates using factory baseline credentials, shifts the Secure Element state to Elite-ready, and opens a transient secure channel
2 P001 Elite Upgrade / Configuration Key Card Payload Delivery: Injects and delivers the proprietary Elite master encryption keys through the channel established by P000.

Critical Warning: Scan Card P000 prior to P001. Reversing this sequence results in a cryptographic handshake failure and key injection rejection. If cards are presented out of sequence, reset the session and restart strictly with P000.

Provisioning Procedure

Step-by-Step Manual Provisioning:

  1. On the Zebra mobile devices, open the HID Provisioning application.
  2. The app opens showing the HID Elite Card. Select Administrator Keys (P000).
  3. Align Card P000 flush against the device's NFC antenna location and hold the card steady for 2 to 3 seconds until the device emits an audible success chime. Antenna locations:
    • HC501: Upper-rear housing, adjacent to the camera and barcode scanner window.
    • ET401: Rear upper-middle region of the chassis. Note: To see the Zebra reader NFC Antenna location go to Settings > Connected Devices > Connection Preferences > NFC.
  4. The success message appears. Tap Done and remove the P000 card from the NFC field.
  5. Return to the main screen and select Configuration Keys (P001).
  6. Present Card P001 flush against the same NFC antenna location. Hold motionless while the cryptographic key injection executes.
  7. When complete, the device emits the success tone.
  8. Tap Done and remove the P001 card from the NFC field. The hardware Secure Element is now permanently provisioned. Exit the application.

Operational Verification:

  1. Open the authorized line-of-business application or the Zebra PACS Credential Validation utility (HID Demo application available for download from Zebra Support site.)
  2. Present an active employee ID badge (e.g., Seos, iCLASS, or DESFire).
  3. Verify that the badge authenticates successfully and outputs the expected Facility Code and Card Number.

Factory Default Rollback

The rollback procedure resets the embedded HID Secure Element from a customer proprietary HID Elite configuration back to the factory standard HID key mode.

Common Rollback Use Cases

  • Device Reassignment/Decommissioning: Reallocating devices to a different site, division, or subsidiary with different credential profiles.
  • Depot Repair: Shipping hardware for repair or maintenance.
  • Key Migration: Upgrading or rotating customer master Elite keys.
  • Error Recovery: Resetting a device after an interrupted provisioning attempt.

Rollback card sets must be procured directly through HID Global referencing the active Elite Program number. Zebra does not stock or generate customer-specific rollback cards. The rollback set consists of two paired physical cards which must follow a specific sequence:

Step Card Card Role / Name Cryptographic Function
1 P002 Elite Downgrade / Config Card Unlock Elite Domain: Authenticates with the active Elite key and opens the Secure Element downgrade channel.
2 P003 Elite Upgrade / Configuration Key Card Restore to Factory Default: Overwrites the Elite keys and restores factory standard HID credentials into the Secure Element enclave.

Critical Warning: Scan Card P002 prior to P003. Reversing this sequence results in a rejection since the Secure Element is still locked under the active Elite program.

Rollback Execution

Step-by-Step Rollback Execution:

  1. In the HID Provisioning application, open the top-right settings menu and toggle Standard Provisioning to ON.
  2. In the HID Standard Card tab, tap Configuration Keys (P003).
  3. Align Card P003 flush against the device's NFC antenna location and hold the card motionless while injecting the cryptographic key, until the device emits an audible success chime.
  4. The success confirmation appears. Tap Done and remove the P003 card from the NFC field.
  5. Return to the main screen and select Administrator Keys (P002).
  6. Present Card P002 flush against the same NFC antenna location. Hold the card motionless while the cryptographic key injection executes.
  7. The success confirmation appears. Tap Done and remove the P003 card from the NFC field.
  8. Tap Done. The device is now restored to standard factory mode.

Post-Rollback Verification:

  • Test Active Elite Badge: Present an organization Elite badge; the device must reject the credential or report an authentication failure.
  • Test Factory Standard Badge: Present a standard factory-keyed HID card; the device must read and output credential data successfully.

Troubleshooting & Diagnostics

Symptom / Error Message Probable Root Cause Recommended Corrective Action
SecurityException / Access Denied Application is not whitelisted in AccessMgr or signed with wrong key. Run SigTools on the application APK and deploy the AccessMgr profile via StageNow (Part I). Verify release key matches.
"Provisioning Failed" on Card P000 Incompatible card or device already provisioned with another Elite key. Confirm genuine P000 card from HID Global. If another Elite key is loaded, execute the Rollback procedure (P002/P003) first.
"Authentication / Key Rejected" on Card P001 Cards presented out of order (P001 scanned before P000). Restart the provisioning session. Present Card P000 first, followed by Card P001.
No response / No beep when card is presented NFC disabled, card held off-target, or thick protective case. Verify NFC is enabled in Android Settings. Align card directly over the antenna sweet spot. Remove metal-shielded cases.
"Key Mismatch" on Rollback Card P002 Card P002 does not match the active Elite Program ID on the device. Ensure Card P002 was ordered for the specific Elite Program ID currently residing on the device.
Read Timeout / Interrupted Communication Card was removed before the write cycle completed. Keep card flush against reader housing until the application sounds the confirmation tone and displays the success prompt.
