管理対象の構成の使用

エンタープライズ ホーム画面 8.0

概要

管理対象の構成は、Google と Android コミュニティによって開発された仕様の一部で、これをサポートするエンタープライズ モビリティ管理 (EMM) システムを通じて、インストールされているアプリケーションとデバイスをリモートで構成するためのものです。管理対象の構成 (MC) は、当初の範囲が限られていたため、当初は「アプリ制限」として知られていましたが、現在では、デバイスのハードウェア、ソフトウェア、セキュリティなどのさまざまな設定をリモートで構成するために Zebra で使用されています。

MC を使用して管理できる特定のアプリの機能は、そのスキーマで定義されます。EHS スキーマは、EMM コンソールを通じて Google Play にアクセスし、管理用に EHS を選択するとダウンロードされます。スキーマは、EMM で使用できる機能を定義し、EMM コンソール内でアプリの管理 UI を表示するために必要な情報を提供します。†このデータ駆動型 UI メソッドを使用すると、新しい .exe をダウンロードすることなく、新しい機能とそれに対応する UI 属性を利用可能になるとすぐに配信できます。管理対象の構成を使用した Zebra デバイスの構成の詳細については、Zebra OEMConfig を参照してください。

†EHS 管理 UI は、使用している EMM システムによって若干異なります。

要件

  • Android 11 以降を実行する 1 台以上の Zebra デバイス
  • Zebra DNA Cloud または EHS を別の EMM と、Google Play からダウンロードされたそのスキーマ
  • EHS 5.0 (以降) がデバイスにインストールされている (必要に応じて EMM によって展開可能)

MC を使用した EHS の構成

重要 - 必ずお読みください!!

すべての MC ファイルには、常に必要な設定をすべて含める必要があります。管理構成内で指定されていないパラメータ設定は、その MC ファイルの展開時にデフォルト設定にリセットされます。EHS が管理対象構成のセットを処理すると、MC ファイルで指定された設定のみを含む新しい enterprisehomescreen.xml 構成ファイルが生成されます。指定されていないその他のパラメータは、すべてデフォルト値にリセットされます。

現時点では、すべての EHS 設定は、 EnterpriseHomeScreen.xml 構成ファイルを介してのみ管理できます。このファイルは手動で編集します。今後 Zebra では、MC を通じて管理できる機能を増やし、すべての機能が含まれるようにする予定です。その時点で、EnterpriseHomeScreen.xml 構成ファイルはオプションになります。

ロール選択グループ

Zebra Identity Guardian (デバイスごとのライセンスが必要) によって有効化されるユーザー ロールに基づいて、デバイス上の EHS を構成します。

重要な注意事項

  • デバイスでロールを使用する場合、既存の enterprisehomescreen.xml プロファイルは「デフォルト」ロール として扱われ、指定されたロール名を持たずに EHS を起動したユーザーに割り当てられます。
  • Zebra は、ロールを追加する前に、組織の要件に応じて、デフォルト ロールで利用可能なアプリ、設定、およびロックダウン機能が適切に定義されていることを確認することを推奨しています。
  • ロール構成ファイルの内容形式は、既存の enterprisehomescreen.xml ファイルと同じです。
  • 他のすべての EHS 構成ファイルと同様に、ロール ファイルはデバイス上の /enterprise/usr フォルダに保存されます。
  • ロール構成ファイルは、指定されているロール名に基づいて命名されます(例: Manager_config.xml)。
  • ロールを削除または更新するには、/enterprise/usr フォルダ内の対応する XML ファイルを削除または置き換えます。
  • Identity Guardian を利用する組織向け:
    • EHS で構成するロール名は、サインイン時に正しくロールを割り当てるため、Identity Guardian で定義されたロール名と完全に一致している必要があります。
    • デバイスの再起動後、Identity Guardian の初期化中は、デフォルト ユーザー向けの EHS ユーザー画面が一時的に表示され、操作可能な状態になります。
