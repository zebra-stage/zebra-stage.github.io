Used to enter the path and filename of an on-device .jpeg or .png image or .mp4 video to display on the screen while the device is in screen-saver mode. On devices with MX 15.3 (or later), entering the name of an on-device folder (with no individual file name) displays all media in that folder in alphabetical sequence, advancing every 20 seconds until the screen saver is exited.

To dismiss screen saver: Touch the screen or click the mouse. Only these methods effectively cancel a screen saver displaying an image or video.

Parm value input rules:

  • Accepts a string of characters corresponding to a valid on-device folder path and file name
  • Supports .jpeg and .png image files and .mp4 video files only
  • On devices with MX 15.3+, file name is optional; displays files as described above
