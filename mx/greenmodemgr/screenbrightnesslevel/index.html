Used to enter a number of percentage points (from 10–30) to reduce device-screen brightness from its current level when ambient light sensors detect a low-light condition. For example, entering 30 reduces the brightness to 50 percent on a device previously set at 80 percent. Screen brightness is NEVER set to less than 30 percent, regardless of the values entered in this parameter or the current brightness level of the device at the time this parameter is applied.

Parm value input rules:

  • Integer from 10–30
