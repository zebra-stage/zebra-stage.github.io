Used to control access to SD Card storage on the device, which includes external, removable SD Card storage. When Disabled (option 2), access to external, removable SD Card storage is completely blocked.

Removable media can become inaccessible by means other than blockage by this CSP. For example, content stored on an unblocked Micro SD card is inaccessible if the card is encrypted and the Named Key has been removed from the Key Storage Database. To learn more, see EncryptMgr.
