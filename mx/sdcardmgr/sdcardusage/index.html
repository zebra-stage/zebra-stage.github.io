Used to control access to SD Card storage on the device, which includes external, removable SD Card storage. When Disabled (option 1), access to SD Card storage is completely blocked. IMPORTANT: Removable media can become inaccessible by means other than blockage by this CSP. For example, an unblocked Micro SD card is inaccessible if physically removed from the device or if encrypted and the Named Key has been removed from the Key Storage Database (see EncryptMgr).
