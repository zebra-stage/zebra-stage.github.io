Used to enter the server URL pointing to a Proxy Auto-configuration (PAC) file, which determines how browser traffic for the device is routed. A PAC file is a text file containing the JavaScript function FindProxyForURL(url, host). Learn more.

Parm value input rules:

  • String from 1–256 characters containing a server URL, path and file name. (e.g. http://CompanyServer.com/pac/proxy.pac)
